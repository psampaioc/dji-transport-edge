# DJI Transport Edge

This repository is one ROS 2 Humble workspace for the Ubuntu edge laptop. It has exactly two packages under `src/`:

- `dji_edge_driver` receives Android telemetry, metadata, clock traffic and H.264/RTP directly. It publishes navigation, source telemetry, diagnostics, and Primary/FPV image topics.
- `dji_edge_mapper` publishes the static point cloud and projects the driver navigation into map pose, path, and TF.

```text
Android tablet -- UDP 5500/5501/5502, RTP 5600/5610 --> dji_edge_driver
                                                      --> dji_edge_mapper --> RViz map/path
```

The Android wire contract is documented in [docs/PROTOCOL_V1.md](docs/PROTOCOL_V1.md). Ports and RTP payload type are fixed until hardware evidence supports a change.

## Workspace layout

```text
src/dji_edge_driver/
src/dji_edge_mapper/
build/ install/ log/       # generated by colcon; ignored by Git
```

Build and run only inside the Humble Docker environment. The operational launch and dashboard work are being completed in the active direct-driver plan: [docs/plans/2026-09-02-1945-refactor-direct-ros-edge-plan.md](docs/plans/2026-09-02-1945-refactor-direct-ros-edge-plan.md).

## Current verification

The root workspace builds in Humble and exposes both packages. The direct driver is still under implementation: hardware bench evidence, dashboard, raw RTP diagnostic capture, and FPV classification remain active work. No flight command is generated by this repository.
